# HR Employee Attrition Analysis

## 📌 Project Overview

HR Employee Attrition Analysis is a data analytics and business intelligence project designed to analyze employee turnover and understand the factors associated with employees leaving an organization.

The project uses Excel, MySQL, Power BI, and DAX to transform employee data into meaningful insights through data analysis, interactive visualizations, and key performance indicators (KPIs).

The dashboard helps HR teams explore attrition patterns across departments, job roles, age groups, gender, salary levels, and overtime status. These insights can support data-driven decisions related to employee retention and workforce planning.

## 🎯 Project Objectives

* Analyze overall employee attrition and retention patterns.
* Calculate key HR performance indicators.
* Identify departments and job roles with higher attrition.
* Explore the relationship between overtime, salary, age, and employee turnover.
* Build an interactive Power BI dashboard for HR data analysis.
* Present findings through clear and meaningful visualizations.
* Support evidence-based employee retention strategies.

## 🛠️ Tools and Technologies

* **Microsoft Excel:** Data inspection, cleaning, and preliminary analysis.
* **MySQL:** Data storage, querying, filtering, aggregation, and analysis.
* **Power BI:** Interactive dashboards and data visualization.
* **DAX:** Calculated measures and KPI development.
* **Data Analytics:** Exploring trends, comparing employee groups, and interpreting patterns.

## 📊 Key Performance Indicators (KPIs)

The dashboard focuses on the following metrics:

* **Total Employees:** Total number of employees included in the analysis.
* **Employees Left:** Number of employees who have left the organization.
* **Attrition Rate:** Percentage of employees who left during the period represented by the dataset.
* **Average Salary:** Average salary of the employees included in the analysis.

## 🔍 Analysis Areas

The project explores employee attrition across several dimensions:

* **Department Analysis:** Compare attrition across different departments.
* **Job Role Analysis:** Examine turnover patterns across job roles.
* **Age Group Analysis:** Explore attrition across employee age groups.
* **Gender Analysis:** Compare attrition patterns by gender.
* **Education Analysis:** Examine patterns across education levels.
* **Overtime Analysis:** Explore whether overtime status is associated with employee attrition.
* **Salary Analysis:** Compare salary patterns among employee groups.

## 📈 Dashboard Features

* Interactive Power BI visualizations.
* KPI cards for quick performance monitoring.
* Department-wise and job-role-wise comparisons.
* Attrition analysis by demographic and employment-related factors.
* Slicers and filters for exploring specific employee groups.
* A consolidated view of workforce attrition patterns.

## ⚙️ Project Workflow

1. **Data Collection:** Obtain the employee attrition dataset for analysis.
2. **Data Preparation:** Inspect the dataset and prepare the data for analysis using Excel.
3. **Database Management:** Load the data into MySQL and perform SQL queries.
4. **Data Modeling:** Prepare the data for reporting in Power BI.
5. **Measure Development:** Create DAX measures for KPIs and other calculations.
6. **Dashboard Development:** Build interactive reports and visualizations.
7. **Insight Generation:** Interpret the results and identify patterns that may help HR teams investigate employee turnover.

## 💡 Expected Business Value

This project demonstrates how data analytics can help organizations better understand employee attrition. By identifying groups with different turnover patterns and examining potential contributing factors, HR teams can investigate retention challenges and make more informed workforce-planning decisions.

The analysis identifies associations and patterns; it does not establish that any single factor directly causes an employee to leave.
